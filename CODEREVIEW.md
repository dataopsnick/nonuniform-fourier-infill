### Top Issues

1. **Benchmark results are corrupted by always-overwriting cubic spline**  
   `tests/benchmark.py`: The fallback `cubic → linear + ffill/bfill` runs unconditionally, overwriting correct cubic spline results. Reported metrics for Cubic Spline are always those of the fallback, misleading any performance comparisons.

2. **Benchmark crashes when GP is skipped**  
   `tests/benchmark.py`: When `n_valid_max > 500`, the `if` branch sets a skip status but does not define `gp_infilled_data` and `gp_time`. Subsequent code references these variables, raising `UnboundLocalError` and crashing the whole benchmark.

3. **Shared log/history corruption under multi-threaded use**  
   `nufi/agent.py`: `TransformationTracker` writes to the same `log_path`/`history_dir` across threads without external locking, leading to truncated, interleaved logs and corrupted history files in concurrent scenarios.

4. **Missing memory guard in Tikhonov solver**  
   `nufi/kernels/torch_kernels.py`: `solve_tikhonov_nudft` builds a full complex matrix `A` of shape `(N, M)` without the size guard that `compute_ND_NUDFT` already uses. For moderate `N` and `M` this can exhaust memory and crash the process.

5. **Deterministic path ignores covariance compensation**  
   `nufi/impute.py`: When `covariance_compensation=True`, the stochastic branch applies `cov_scale` and maps residuals back; the deterministic branch does not, producing inconsistent (and likely biased) reconstructions for compensated models.

6. **`best_n_freq` always equals `N_val` – intended capping is inactive**  
   `nufi/impute.py`: `best_n_freq = min(max(5, N_val), N_val)` always evaluates to `N_val`. The “avoid underdetermined system” logic never triggers, so the solver may receive more frequencies than intended, risking instability for small `N_val`.

7. **`check_is_fitted` missing before `transform()`**  
   `nufi/impute.py`: Calling `transform()` on an unfitted instance raises a cryptic `AttributeError` instead of a clear `NotFittedError`, harming developer experience.

8. **Exception masking during failure logging**  
   `nufi/agent.py`: If `log_transformation` itself fails inside the exception handler, the new `TransformationLoggingError` replaces the original error, hiding the true root cause from the caller.

9. **Silent edge artifacts from `np.interp` clipping and truncated Nyquist frequencies**  
   `nufi/kernels/torch_kernels.py`: Floating-point-induced out-of-range values are clipped by `np.interp` without warning, and the median-interval Nyquist heuristic can silently discard high-frequency content, both degrading reconstruction quality with no user indication.

10. **PyTorch forced as a mandatory ≥2 GB dependency**  
    `pyproject.toml`: `torch` is a hard requirement, but GPU acceleration is described as optional. This imposes a massive install footprint on all users and can cause dependency conflicts; it should be moved to an optional extra.

### Module Hotspots

- **`tests/benchmark.py`** – Two critical bugs (overwrite, `UnboundLocalError`) plus an unguarded constructor that can crash. Density of impactful findings is the highest in the repo.
- **`nufi/kernels/torch_kernels.py`** – Multiple numerical robustness and safety gaps: missing length validation, fragile regularization, missing memory guard, Nyquist truncation, `np.interp` clipping, fragile `valid_idx` API. Central computation kernel with several silent-failure paths.
- **`nufi/agent.py`** – Concurrency corruption, orphan snapshots, exception masking, diagnostic inconsistency, late validation. Orchestration layer has several data-safety and error-reporting flaws.
- **`nufi/wrappers.py`** – Concentrated validation deficiencies: missing NaN/monotonicity checks, timestamp precision loss, `np.array_equal` NaN sensitivity, `keep_time_col` duplication, unsorted silent acceptance.
- **`tests/test_imputer.py`** – Overly lenient tolerances (`rtol=0.5`, GCV bound `3× col_range`), missing verification of non-NaN columns, zero‑alpha not tested, weak stochastic assertion, uncovered `keep_time_col=False` path.
- **`nufi/impute.py`** – Bugs in frequency selection, missing covariance compensation, unfitted guard, code duplication.
